Why Scale-to-Zero Wins for Enterprises

In typical enterprise environments (8 hours active traffic per workday), servers sit completely idle during nights, weekends, and holidays (~65% of total time). Cloud Run scales instances to 0 when idle, saving $450–$600 per month compared to 24/7 dedicated GKE nodes.

💻 Developer Integration & API Snippets

OpenAI Compatible

vLLM implements the standard OpenAI specification. You can swap any OpenAI-compatible SDK (Python, Node.js, LangChain, LlamaIndex, LiteLLM) simply by pointing the base_url to your Google Cloud Run endpoint.

cURL (Streaming SSE)

curl -X POST "${SERVICE_URL}/v1/chat/completions" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer ${VLLM_API_KEY}" \
  -d '{
    "model": "qwen-7b",
    "messages": [
      {"role": "system", "content": "You are a helpful assistant."},
      {"role": "user", "content": "Explain PagedAttention in 2 sentences."}
    ],
    "stream": true
  }'

Python (Official OpenAI SDK)

from openai import OpenAI

client = OpenAI(
    base_url="${SERVICE_URL}/v1",
    api_key="${VLLM_API_KEY}"
)

stream = client.chat.completions.create(
    model="qwen-7b",
    messages=[{"role": "user", "content": "Hello vLLM on GCP Cloud Run!"}],
    stream=True
)

for chunk in stream:
    print(chunk.choices[0].delta.content or "", end="", flush=True)
